# agent-deck 利用者ガイド

agent-deck は、あらかじめ役割を決めた AI エージェントに定型業務(アンケート集計、予算分析などの
レポート作成)を依頼し、作業の様子を見ながら成果物ファイルを受け取るためのアプリです。
このガイドはアプリを使う人向けです。開発者向けの情報は [development.md](development.md) にあります。

## 1. はじめて使うとき

### 必要なもの

1. **agent-deck.exe** — もらった exe ファイルを、書き込みできる好きなフォルダに置くだけで使えます
   (インストール不要。「Program Files」の中には置かないでください)
2. **GitHub Copilot CLI** — コマンドプロンプトで `copilot` と打って起動すれば OK。
   入っていない場合は `winget install GitHub.Copilot` でインストールし、
   `copilot login` の指示に従って一度ログインしてください
3. **Copilot の利用権** — 会社の GitHub Copilot が使えるアカウントが必要です

### 初回起動

exe をダブルクリックすると、exe と同じ場所に `data` フォルダが自動で作られます。
設定・履歴・ログはすべてこの中に入るので、**フォルダごとコピーすれば引っ越しできます**。

## 2. 画面の見方

| 場所 | 内容 |
|---|---|
| 左 | エージェント一覧(設定は「⚙ 設定を開く」で別ウインドウ) |
| 中央 | 実行ビュー。依頼の入力と、作業の様子(ツリー表示) |
| 右 | 詳細。ログ・トークン使用量・できあがったファイル |
| 下 | 実行履歴 |

エージェント名の横のバッジの意味:
- **個人** / **共有** — 自分だけの定義か、チーム共有の定義か
- **⚠ 未設定** — 入力・出力フォルダがまだ設定されていない(下記 3. を先にやってください)

## 3. 最初の設定(エージェントごとに一度だけ)

左の一覧でエージェントを選び、「⚙ 設定を開く」(または一覧の行をダブルクリック)。
別ウインドウが開くので、「入出力設定」で:

1. **入力フォルダ** — 集計してほしいデータ(CSV など)を置く場所
2. **出力フォルダ** — レポートなどの成果物を受け取る場所
3. 自動承認ツールの「ファイル書き込み(出力フォルダの中のみ)」は**オンのまま**が便利です
4. 「自動承認ツール」は、承認ダイアログなしで実行を許可する操作の種類です
   (通常は空のままで OK。実行中に「常に許可」を選ぶと自動で追加されていきます)
5. 「保存」を押す

自分用のエージェントは、同じウインドウの「定義」で **ID(名前)を後から変更できます**。
ID を書き換えて「保存」を押すと、入出力設定・スケジュール・作業フォルダも一緒に移ります
(履歴は当時の ID のまま残ります)。実行中のエージェントは変更できません。

ファイル書き込みの承認はフォルダで分かれています: **出力フォルダの中は自動承認
(チェックボックス)、外は毎回確認**。「自動承認ツール」の write はこの区別を
なくしてしまうため、通常はチェックしないでください。

## 4. 仕事を頼む

1. 入力フォルダにデータファイルを置く
2. エージェントを選び、依頼内容を入力して「実行」
   - 例: 「input フォルダの 2026Q2 のアンケートを集計して、前回との比較付きでレポートを作って」
3. 作業の様子が中央にリアルタイムで表示されます
   - 🔧 の行は、エージェントが使っている道具(ファイル読み書き、スクリプト実行など)
   - インデントされた行は、手伝いをしている別のエージェント(完了すると所要時間が出ます)
4. 終わると右側に**できあがったファイルの一覧**が出ます。「出力フォルダを開く」でエクスプローラが開きます

### 承認を求められたら

エージェントが**出力フォルダの外**に書き込もうとしたときなどは、作業が一時停止して
承認ダイアログが出ます。内容(何をどこにしようとしているか)を読んで:

- 「今回のみ承認」 — この 1 回だけ許可して作業が続きます
- 「常に許可」 — 同じ種類の操作(例: Web アクセス)を、このエージェントでは以後確認なしで
  許可します(設定の許可ツールに自動で追加されます)。毎回同じ確認が出て煩わしいときに
- 「拒否」 — **作業は安全に中断されます**

### エージェントから質問されたら

作業に必要な情報が足りないとき、エージェントが質問してくることがあります。
質問カードが該当行の下に表示されるので、選択肢を選ぶか自由入力で答えてください。
「回答しない」を選ぶとエージェントは回答なしで作業を続けます。

### 終わった後に続きを頼むには

完了したタスクの下に**返信欄**があります。「〜しますか?」と聞かれて終わった場合や、
結果に対して追加の依頼(「これを英語にして」など)をしたい場合は、ここに入力して
「返信して続行」を押すと、**文脈を引き継いだまま**同じ会話の続きが実行されます。

### 中断したいとき

「中断」ボタンでいつでも止められます。履歴には「中断」と記録されます。

## 5. 履歴と成果物の見方

下の履歴には、いつ・どのエージェントが・どれだけ時間をかけて・成功したかが残ります。

**「⚠ 出力は未完成の可能性」と出ている行に注意。** 失敗・中断した実行の出力フォルダには
作りかけのファイルが残っていることがあります。その実行の成果物は使わないでください。

数字の根拠を確かめたいとき: エージェントは集計を Python スクリプトで行い、そのスクリプトも
出力フォルダに保存されます。レポートの数字はスクリプトの出力と一致しているはずです。

## 6. 定期実行(スケジュール)

「毎月 1 日の 9 時にアンケート集計」のような予約ができます。設定エリアの「スケジュール」から
エージェント・依頼文・繰り返し(毎日/毎週/毎月+時刻)を登録してください。

注意:
- **アプリを起動している間だけ**動きます(閉じていた間の分は、次に起動したとき 1 回だけ実行されます)
- 予約実行中は承認ダイアログが出せないため、**事前に承認されていない操作は自動で拒否され、
  その実行は失敗として記録されます**。定期実行するエージェントは、出力フォルダの設定と
  許可ツールを事前に整えておいてください
- 終わると Windows の通知でお知らせします

## 7. チーム共有の定義と更新

- **共有エージェント**: 管理者が用意した共有フォルダから「同期」ボタンで取り込めます。
  共有定義は編集できません。カスタマイズしたいときは設定ウインドウの「複製して編集」で自分用のコピーを作ります
  (同じ名前の自分用があると、そちらが優先されます)
- **アプリの更新**: 新しいバージョンが配布されると、起動時に画面上部にお知らせが出ます。
  「⚠ ハッシュが一致しません」と出た場合は配布物が壊れている可能性があるので、
  適用せず管理者に連絡してください

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 「Copilot CLI が見つかりません」 | `winget install GitHub.Copilot` でインストール。入れた直後はアプリを再起動 |
| 「not authorized」「organization policy」を含むエラー | 会社側で Copilot CLI が許可されていません。管理者に確認してください |
| 「login」「authentication」を含むエラー | コマンドプロンプトで `copilot login` を実行して認証し直してください |
| 「データフォルダに書き込めません」 | exe が書き込み禁止の場所にあります。ドキュメント配下などに移動してください |
| 実行がすぐ「失敗」になる(定期実行) | 承認が必要な操作を含んでいます。出力フォルダ設定と許可ツールを見直してください |
| レポートの数字が怪しい | 出力フォルダの集計スクリプト(.py)を開き、実行結果と照合してください。それでも不明なら履歴の日時を添えて開発者へ |

すべての操作記録(監査ログ)は「監査ログフォルダを開く」から確認できます。
問い合わせのときは、履歴に出ている日時とエージェント名を添えてください。
