# 要求仕様

agent-deck が「何を」実現するかを定義する文書。実現方法は [architecture.md](architecture.md)、
進め方は [development.md](development.md)、将来の拡張は [roadmap.md](roadmap.md) を参照。
未決事項([open-questions.md](open-questions.md))は独断で決めないこと。

## 1. 目的

役割を定義した AI エージェントに定型業務を依頼し、その稼働状況をリアルタイムに把握し、
成果物ファイルを受け取るための Windows デスクトップアプリケーション。

### 1.1 想定する業務

コード生成ではなく、**業務ドキュメントの生成**が主用途。

- アンケート結果の集計と分析レポートの作成
- 予算消費状況の分析レポートの作成
- その他、入力データ → 分析 → レポート出力の形をとる定型業務

### 1.2 利用者

- 一次利用者: 開発者本人
- 二次利用者: 同一チームのメンバー(数名)。**エンジニアとは限らない**

### 1.3 名称

**`agent-deck`**(2026-08-12 決定。当初の仮称は `agent-console`)

### 1.4 配布形態

インストーラーなしのポータブル exe。任意のフォルダに置いて起動でき、インストールを要求しない。
(実現方式の裏付けは [sdk-notes.md](sdk-notes.md) の Tauri 節を参照)

## 2. スコープ

### 2.1 v0.1 に含めるもの

- [ ] エージェント一覧の表示(`.agent.md` を読み込んで表示)
- [ ] エージェントへのタスク依頼(プロンプト入力 → 実行)
- [ ] 実行中の状況のリアルタイム表示(メイン/サブエージェントのツリー)
- [ ] エージェントごとの入力・出力フォルダの設定と永続化
- [ ] 出力フォルダ配下への書き込みの自動承認、それ以外の承認ダイアログ
- [ ] 実行履歴の記録(いつ・どのエージェント・所要時間・成否)

### 2.2 拡張機能(v0.2〜v1.0 で実装済み)

| 機能 | 実装版 | 概要 |
|---|---|---|
| 定義の編集 UI・スコープ分離・共有フォルダ同期 | v0.2 | 個人(編集可)/共有(読み取り専用+複製して編集)。定義バージョン表示 |
| アプリ更新の検知と通知 | v0.3 | 配布フォルダのマニフェスト + sha256 検証。通知のみ(自動適用しない) |
| 定期実行と通知 | v0.4 | 毎日/毎週/毎月+時刻。アプリ起動中のみ。無人実行は未承認操作を即拒否 |
| 並行実行とダッシュボード | v0.5 | 上限は設定値(既定 2)。同一出力フォルダは排他 |
| 監査ログ・来歴・管理者ポリシー・ログ保持期間 | v0.6 | セッション単位の全操作記録、成果物の来歴、forcedDeniedTools |
| エージェントの質問への回答 | v1.0 | `ask_user` を有効化し、該当行の直下に質問カード。無人実行では即「回答なし」 |
| 継続依頼(会話の保持とレジューム) | v1.0 | 完了・中断したセッションへの返信で文脈を継承。履歴から会話を復元して続行 |
| 承認の 3 択化 | v1.0 | 今回のみ / 常に許可(このエージェント) / 拒否。write には「常に許可」を提案しない |
| 定義・入出力設定の別ウインドウ化とツール複数選択 | v1.0 | §3.4。ツールは公式エイリアスのチェックボックス + 手入力欄 |
| 出力フォルダのパスをモデルへ伝達 | v1.0 | 送信本文の先頭に `[環境情報]` として実パスを注入(履歴・会話表示は生の依頼文) |
| エージェント定義の下書き生成 | v1.1 | やりたいことの説明から name/description/tools/本文を Copilot が下書きし、定義エディタに反映。保存は人が押すまで行わない。生成セッションはツールを持たず(`tools: []`)、model は生成させない |

### 2.3 スコープ外(実装しないもの)

- 認証情報の保存(Copilot CLI 側の認証に委ねる)
- アプリの自動ダウンロード・自動適用(検知と通知まで)
- GitHub リポジトリからの定義同期・更新配布(配布元と認証方式が未決 — [open-questions.md](open-questions.md))
- 常駐(タスクトレイ)によるウィンドウ非表示中の定期実行(未決 #7)

## 3. 画面仕様

### 3.1 レイアウト

3 ペイン構成。

```
┌───────────┬──────────────────────────┬─────────────┐
│ エージェント │ 実行ビュー                  │ 詳細         │
│ 一覧       │  - プロンプト入力            │  - ログ      │
│            │  - 実行中のツリー            │  - トークン   │
│            │  - 進行状況                  │  - 出力       │
│            │                            │    ファイル   │
├───────────┼──────────────────────────┴─────────────┤
│ 設定        │ 実行履歴                                 │
└───────────┴────────────────────────────────────────┘
```

### 3.2 エージェント一覧(左ペイン)

- `.agent.md` から取得した名前・説明を表示
- 入出力フォルダが未設定のものはバッジで示す
- 選択すると実行ビューに反映

### 3.3 実行ビュー(中央ペイン)

**リアルタイム表示がこのアプリの主目的**。ここを最も丁寧に作る。

```
▼ survey-analyst                          実行中  2:31
  現在: 集計スクリプトを実行しています
  │
  ├─ 🔧 bash: python analyze.py           完了  0:12
  ├─ ▼ data-cruncher (サブ)               実行中  1:04
  │    └─ 🔧 read: survey_2026Q2.csv      完了
  └─ ○ report-writer (サブ)               待機
```

- サブエージェントは親の下にインデントして表示
- 完了したサブエージェントには所要時間とトークン数を出す
- 承認要求が発生したら、該当行の直下にダイアログを出す

### 3.4 設定画面

エージェントごとの定義(名前・説明・モデル・ツール・本文)と、入力フォルダ・
出力フォルダ・許可ツールを設定。フォルダはダイアログで選択できるようにする。

使う頻度が低いので**別ウインドウ**で開く(一覧ペインを占有させない)。一覧の
「⚙ 設定を開く」ボタンか行のダブルクリック、および新規作成の直後に開く。
保存するとメインウインドウの一覧へ反映される。

### 3.5 UI 方針

- 情報密度を優先する。装飾は最小限
- 状態は色だけで表現しない(アイコンとテキストを併用)
- 日本語表示。フォントサイズは 13px 以上

## 4. 受け入れ条件(v0.1)

以下がすべて満たされたら v0.1 完了とする。

1. exe を任意のフォルダに置いて起動でき、インストールを要求しない
2. エージェント一覧に、定義フォルダ内の `.agent.md` がすべて表示される
3. エージェントを選び、プロンプトを入力して実行できる
4. 実行中、メインエージェントの現在の動作がリアルタイムに表示される
5. サブエージェントが起動した場合、ツリー上に別行として現れ、完了時に所要時間が出る
6. 出力フォルダ配下への書き込みは承認なしで進む
7. 出力フォルダ外への書き込みは承認ダイアログが出て、拒否すると実行が止まる
8. 実行が完了すると、生成されたファイルの一覧が表示され、フォルダを開ける
9. アプリを再起動しても、エージェントごとの入出力設定が保持されている
10. 実行履歴に、直近の実行が記録されている
